订阅之后，怎么用起来

四步，不需要技术背景。

从下单到连上

  1. 先看清档位 对照上方的流量与设备数，选一个够用又不浪费的。一个人日常刷手机，基础版通常就够；家里几台设备一起用，直接看旗舰版。
  2. 拿到订阅信息 开通后你会收到自己的订阅凭据。它像钥匙，自己收好，别随手转给别人。
  3. 在客户端里填入 打开你设备上的客户端，按界面提示把订阅凭据添加进去，再选一个线路。
  4. 验证一下再开始用 连接成功后随便打开一个网页确认能正常加载，再去看视频、打游戏，避免中途才发现设置不对。

几句实在的提醒

同一档位的设备数指的是同时在线的上限，不是历史登录次数。换新手机前先在旧设备上退出，能省下一次占用。

流量按自然月计算，这个月没用完的部分不会累加到下个月，所以别为了“攒着”硬撑一个小档位。

按年付比按月付省下两个月，适合已经确定会长期使用的人。第一次用，先按月试试水更稳妥。

客户端这块，我们不说满话

我们不做自带客户端，你需要用设备上现有的工具来接入。

你需要准备什么

CheapV2 提供的是订阅凭据，不是一个安装在手机里的应用。接入用的客户端由你自己选择，安装包请从对应项目的官方发布渠道获取——我们不在这一页提供下载链接，也不会替你打包。

  • 桌面端（Windows / macOS / Linux）使用系统上常见的同类客户端
  • 移动端（Android / iOS）通过对应应用商店或官方渠道获取
  • 路由器 / 软路由团队版可配合企业定制路由使用

具体哪些客户端与你手上的系统版本兼容，请以客户端自身的官方说明为准；我们不掌握你设备的实际环境，也就不做兼容性承诺。

常见问题

按被问到的频率从高到低排。

  1. 三个档位里，我该选哪个？

    先数一下你有几台设备要同时在线，再看每月大概用多少流量。一个人两三台设备、看看视频刷刷网页，基础版就够了；家里或办公室多人共用，旗舰版更合适；十几二十台设备一起跑、还要定制路由的，直接看团队版。拿不准就从低档开始，不够再换。

  2. 按年付到底省多少？

    年付价格是月付的十个月，也就是少掏两个月。基础版 ¥150 / 年、旗舰版 ¥350 / 年、团队版 ¥850 / 年，对应关系都是这样算出来的。

  3. “设备同时在线”是怎么算的？

    指的是同一时刻正在连接的最大设备数量。基础版 3 台、旗舰版 5 台、团队版 20 台。手机上登过再退出，就不算在占用里了。

  4. 流量没用完会留到下个月吗？

    不会。额度按自然月刷新，未用完的部分不结转。如果你经常月中就顶到上限，说明该往上一档走了。

  5. 需要另外装你们自己的 App 吗？

    不需要，因为我们没有自研客户端。你用的是设备上已有的接入工具，把订阅凭据填进去即可。安装包请从对应客户端的官方渠道获取，别从来路不明的网盘下。

  6. 旗舰版里的 IPLC 专线是什么意思？

    这是旗舰版线路配置中的一个组成项，主要面向对延迟敏感的场景。它不代表任何具体数值上的性能承诺，实际体验会受你所在地、运营商和时段影响。我们宁可把话说保守一点，也不想让你抱着不切实际的预期。

  7. 用起来有问题，怎么找你们？

    旗舰版含 7x24 优先工单支持，团队版另有专属客户经理。基础版用户也可以通过常规工单渠道联系我们，只是处理顺序会排在优先工单之后。
